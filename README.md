# 木构架交互图谱 · 中国建筑史（浙大 355）复习系统

**在线访问：[https://galileo21stt.github.io/mugoujia-site/](https://galileo21stt.github.io/mugoujia-site/)**（电脑、手机均可直接点击打开，无需下载）

一个离线就能用的静态网页，帮你把中国古代木构架"看懂、记住、会画、会讲"。电脑和手机都能用。

## 怎么打开

- **直接打开**：双击 `site/index.html`（用 Chrome / Edge / Safari 打开都可以）。不需要联网、服务器或构建步骤。
- **手机**：把整个 `site/` 文件夹拷到手机，用浏览器打开 `index.html`；或者部署到任意静态托管（GitHub Pages、Netlify、Vercel 等），把 `site/` 作为根目录即可。
- 页面地址后面加 `#模块名` 可以直接跳到某个模块，例如 `index.html#fashi`、`index.html#draw/tingtang`、`index.html#cases/foguang`。

## 技术说明

- 纯 HTML + CSS + 原生 JS + 内联 SVG，没有任何依赖或构建步骤；整站约 3.5 MB（大部分是图片）。
- 所有结构图都由 `models.js` 中的坐标生成：构件是独立 SVG 组，带类别、名称、说明、拆解位移、绘制顺序。修改某个构件只需改一处坐标。
- 标注有两种模式：宽屏用引线标注；窄屏（< 700px）自动改用"编号＋图例"，手机上也看得清。
- 厅堂、殿堂的屋面坡度由 `juzhe()` 按《营造法式》"举折之制"计算（先定举高，各缝依次下折 H/10、H/20、H/40）。
- 截图用 `node tools/cdp.mjs <配置.json>` 生成（通过 Chrome DevTools 协议驱动本机 Chrome，无需 Playwright）。

## 证据分级（全站统一）

- 〔教材p.x〕：潘谷西主编《中国建筑史》第7版。页码是按 OCR 文本版"教材页码"标记核出的印刷页码，不是 P 坐标。
- 〔真题 ID〕：本地真题库记录。2025、2026 年的题来自补充扫描，**非官方**。
- 示意：本站绘制的结构示意图，构件关系有依据，尺寸和细部经过简化，**不是测绘图**。
- 〔AI解释〕〔待核〕：理解性概括或尚未核实的细节。

## 已知限制

- 南禅寺、晋祠圣母殿、太和殿没有可靠的剖面数据，所以没有画它们的构架细节（圣母殿只做了"生起"概念演示）。
- 厅堂命名解码器只有"八架椽屋前后乳栿用四柱"对照过复原图，其余柱位是按命名规则推出来的，还需要对照《法式》原图。
- 教材图片从本地 OCR 资料中提取，仅供个人复习，不要公开分发；台北科大复原图是 CC BY-NC-SA 4.0 许可（禁止商用）。
- 教材图片仅供个人复习，不要公开分发。

## 怎么部署（可选）

1. 把 `site/` 整个文件夹推到一个 GitHub 仓库的根目录（或 `docs/` / `gh-pages` 分支）。
2. 在仓库 Settings → Pages 里选该目录作为发布源。
3. 打开生成的 `https://<user>.github.io/<repo>/` 即可；手机浏览器也能用。
4. Netlify / Vercel / Cloudflare Pages：直接把 `site/` 拖上去或指定为发布根目录，同样不需要构建命令。
